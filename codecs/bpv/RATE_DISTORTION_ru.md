# Rate–distortion в BPV1

Экспериментальный модуль `src/bpv1-rate-distortion.js` выбирает запись
каждого блока 4×4 по критерию:

```text
J = D + λR
```

- `D` — точная RGB SSE по 16 пикселям блока;
- `R` — оценка переменной части записи: `SKIP=0`, `MOTION=8`,
  `BLOCK_DICT=16`, локальный `RAW=16/32/56` бит;
- фиксированные 2 бита карты режимов не учитываются, поскольку одинаковы для
  всех вариантов.

Кодировщик рассматривает несколько ближайших автоматически построенных BPAL-
палитр и блок с той же позиции предыдущего декодированного кадра. После выбора
обычный BPV1-кодировщик выполняет точный поиск `SKIP`, `MOTION` и словарных
ссылок.

При `λ=0` выбирается минимальная ошибка среди кандидатов. Увеличение `λ`
разрешает небольшое ухудшение блока, когда это заметно уменьшает поток.

Формат BPV1 v6 и декодер не меняются. Следовательно, объём RAM и вычислительная
сложность микроконтроллерного декодера остаются прежними; дополнительные
вычисления выполняются только на стороне кодировщика.
